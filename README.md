# GetJob

A modern job marketplace web application.

## Tech stack
- Frontend: React + Vite
- Linting: ESLint

## Quick start
```bash
# Install deps
cd frontend && npm install

# Start dev server
npm run dev
```

## Project structure
```
backend/
frontend/
rabbit-assets-main/
```

## Environments
Create an `.env` or `.env.local` in `frontend/` based on `.env.example`.

## Scripts (frontend)
- `npm run dev`: start dev server
- `npm run build`: production build
- `npm run preview`: preview build
- `npm run lint`: run ESLint
